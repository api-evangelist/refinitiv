# Refinitiv GraphQL API

Refinitiv (now LSEG Data & Analytics) provides financial data, trading infrastructure, and analytics. The API covers real-time market data, historical prices, reference data, news, ESG scores, and financial calendars for capital markets applications.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Refinitiv REST API
**Documentation:** https://developers.lseg.com/en/api-catalog/refinitiv-data-platform/refinitiv-data-platform-apis/documentation

- Reference: https://apidocs.refinitiv.com/Apps/ApiDocs
